Overview

SILVA-MCP is a Model Context Protocol server that exposes the SILVA rRNA database's web-service APIs as tools callable by Large Language Models (LLMs). It enables AI assistants to search sequences, retrieve detailed metadata, match probes and primers, and browse the SILVA taxonomy — all through the standardized MCP interface.

SILVA is a comprehensive online resource for quality checked and regularly updated ribosomal RNA (rRNA) sequence databases, maintained by the DSMZ (Leibniz Institute DSMZ — German Collection of Microorganisms and Cell Cultures GmbH). SILVA provides aligned small (16S/18S, SSU) and large subunit (23S/28S, LSU) rRNA sequences for all three domains of life (Bacteria, Archaea, and Eukarya).

Features

🔍

Sequence Search

Search the SILVA database by organism name, accession number, strain, taxonomy, sequence length, quality, and more — with multi-field AND logic.

📄

Sequence Detail Retrieval

Get comprehensive metadata for a specific sequence, including multi-taxonomy classifications (SILVA, LPSN, GTDB, ENA), environmental metadata, and publication references.

🧬

TestProbe

Submit a probe or primer sequence to find all matching sequences in the SILVA database with configurable mismatch tolerance (TestProbe 3.0).

⚗

TestPrime

Evaluate the coverage and specificity of a forward/reverse primer pair against the entire SILVA database (TestPrime 1.0).

🌳

Taxonomy Browser

Generate direct URLs to the SILVA taxonomy browser for interactive exploration of sequence taxonomic context.

📚

Database Listing

Enumerate available databases and their supported taxonomy classification systems.

Available Tools

Tool Description
silva_search Search for rRNA sequences matching one or more criteria
silva_sequence_detail Get detailed information about a single sequence
silva_testprobe Match a probe/primer against the SILVA database (TestProbe 3.0)
silva_testprime Evaluate a primer pair's coverage and specificity (TestPrime 1.0)
silva_browser Get the SILVA taxonomy browser URL for a sequence
silva_list_databases List available databases and their taxonomies

Architecture

The server communicates over stdio using the MCP protocol. When an MCP client sends a tool-call request, the server validates arguments with Zod schemas, dispatches to the SILVA web-service client, and returns parsed JSON results.

MCP Client Claude Desktop, Cursor, …
→
SILVA-MCP Server stdio transport · Zod validation
→
SILVA Web Service legatum.arb-silva.de/WS/

Installation & Configuration

Prerequisites

  • Node.js ≥ 18.0.0 (tested on Node.js 20+)
  • An MCP-compatible client (e.g., Claude Desktop, Cursor, or any MCP SDK consumer)

Build from Source

git clone https://github.com/ZengZichao/SILVA-MCP.git
cd SILVA-MCP
npm install
npm run build

Configure Your MCP Client

Add the SILVA-MCP server to your MCP client's configuration file:

{
  "mcpServers": {
    "silva-mcp": {
      "command": "node",
      "args": ["/absolute/path/to/SILVA-MCP/dist/index.js"]
    }
  }
}

Example Usage

Once configured, the tools are available to your AI assistant. You can ask questions like:

  • “Search the SILVA database for sequences from the organism Escherichia coli”
  • “Find the sequence detail for SILVA ID 12893389 in the SSU database”
  • “Test the probe CGCCTCCCTCTACCGTTT against the SSU RefNR database with 1 mismatch”
  • “Evaluate the primer pair AGAGTTTGATCCTGGCTCAG and GGTTACCTTGTTACGACTT against SSU r144”
  • “What databases are available in SILVA?”

SILVA Databases

Database ID Description Type
ssu-144 SSU Ref/RefNR release 144 (16S/18S) Small Subunit
lsu-138.2 LSU Ref/RefNR release 138.2 (23S/28S) Large Subunit

The current SILVA release 144 contains over 2.2 million SSU and 350,000 LSU aligned rRNA sequences. SILVA provides its own taxonomy, plus mappings to LPSN, GTDB, ENA, LTP, and RDP classification systems.
